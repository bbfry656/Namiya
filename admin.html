Сохранить через GitHub

1. Скачайте подготовленное фото.
2. Откройте загрузку в GitHub, добавьте скачанный файл hero-portrait.jpg и нажмите Commit changes. Имя файла менять не нужно.

Достаточно войти в аккаунт GitHub с доступом к сайту. После сохранения сайт обновится через несколько минут.

Публикация прямо отсюда — для владельца сайта

Для сохранения через GitHub нужен аккаунт с правом записи в репозиторий bbfry656/Namiya. Владелец сайта может пригласить аккаунт Насти в настройках репозитория. Для публикации токеном ниже используйте аккаунт владельца bbfry656.

В GitHub создайте fine-grained personal access token: выберите владельца bbfry656, только репозиторий Namiya и разрешение Contents: Read and write. Если аккаунту недоступен этот выбор, попросите владельца настроить доступ. Укажите ограниченный срок действия.

Вставьте токен ниже перед публикацией. Он отправляется только в GitHub, не сохраняется в браузере и очищается после успешной публикации. Не передавайте его другим людям.
